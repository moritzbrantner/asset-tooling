# Native shrubs from the existing tree recipe

Run `bun examples/shrubs/build.ts [absolute-or-caller-relative-sapling-archive]` with the declared Blender available, then `python3 examples/shrubs/review.py` (Pillow). The default archive is the already accepted local `.artifacts/sapling/sapling-0.3.7.zip`; there is no acquisition or ambient extension installation. Output paths resolve from the scripts.

The public `TREE_PRESETS.shrub` keeps Sapling's broadleaf family and the existing full tree controls. It selects a 1.1m compact shrub with twenty primary/four secondary branches, 70° branch angle, foliage density 320 and 0.16m native leaf-scale control. Upright and loose fixtures change height/angle or branch/foliage density at the same seed and material palette. Branch/leaf controls must retain native ground compatibility; unsupported combinations still fail closed rather than moving geometry above ground.

Six actual GLBs comprise three composed appearances and independent compact trunk/branches/foliage outputs. Component geometry hashes match the composed source. All retain native UVs/normals, meter/Y-up units, identity transforms and ground anchoring. Static import validates each; cache-independent native verification rebuilds every output.

Three transparent native renders use one explicit 2.2m world span and ground pivot. The inspector ties each displayed image to its current source/script/spec/receipt/output pins and marks the common anchor. This producer comparison is not a game camera, species model, multistem shrub guarantee or consumer spacing/collision approval. No wind/runtime vegetation or game RNG/state authority is introduced.

The existing static bundle profile distributes all six meshes and three previews, retains complete AssetRefs/lineage, compares cold exports and loads all nine assets after deleting the cold object store. Repeated generation reconciles identical output and receipts. Outputs/screenshots under `.artifacts/shrubs` stay disposable; real Raid Defense/Zoo integration remains read-only and #133 stays open.
